# Predicción de intención de compra en e-commerce

Trabajo final de Business Predictive Analytics (UPC), Grupo 2, sección 9341.

App de Streamlit con 4 secciones: exploración de datos, entrenamiento (XGBoost sin balanceo y con SMOTE), predicción de una sesión (probabilidad de `revenue = True`) y análisis de resultados. Sigue el formato de la app de ejemplo del curso.

- `app.py`: la app (mismos pasos y parámetros del notebook).
- `online_shoppers_intention.csv`: dataset de UCI (Sakar et al., 2019).
- `requirements.txt` y `runtime.txt`: librerías y versión de Python.
